# QuantaKrypto Workshops

Talleres prácticos para entender y probar criptografía con datos de ejemplo.

## LABITCONF 2026

[Entrar al taller](labitconf2026/README.md): elegí entre mensaje híbrido, recibo firmado o exposición de UTXOs. Cada carpeta incluye su código, dependencias, pruebas y guía.

Para descargar todo, usá **Code → Download ZIP** o:

```sh
git clone https://github.com/quantakrypto/workshops.git
cd workshops/labitconf2026
```

Las demos funcionan localmente. No se conectan a wallets, relays ni redes de pago. Usan claves nuevas de prueba; no cargues secretos ni fondos reales.
